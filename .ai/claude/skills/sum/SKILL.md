# Sum

计算两个输入值的和。

## 使用方式

- 当用户已经一次性给出两个值时，直接计算。
- 当用户只输入 `/sum`、`sum`、`求和` 这类触发语而没有给出两个值时，先要求用户输入第一个值。
- 收到第一个值后，再要求用户输入第二个值。
- 使用 `Number(...)` 的语义判断两个输入是否为有效数字。
- 如果任一输入不是有效数字，输出 `输入无效`。

## 输出

```
<值1> + <值2> = <和>
```

例如：输入 `1` 和 `2`，输出 `1 + 2 = 3`。

## 规则

- 成功时仅输出结果行，不要附加解释。
- 缺少参数时，按两步交互依次索取两个值，不要要求用户重新使用 `/sum <值1> <值2>`。
- 无效输入时仅输出：`输入无效`
